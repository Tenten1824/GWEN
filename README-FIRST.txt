REQUIRED UPDATE POLICY (1.19.28 and later)
GWEN Public checks the official signed release notice at startup when online.
A verified mandatory minimum version prevents new playback until the required
update is installed and GWEN restarted. An ongoing game or recording is not
terminated. You approve download/preparation; GWEN does not run an installer
without your action. A previously verified requirement is remembered offline.
An offline client with no verified requirement continues to work. Required
checks are separate from optional daily notifications. Older Public clients
(1.19.23 and earlier) do not implement enforcement and must accept this update
once. The installer preserves existing saved data and update-channel separation.
